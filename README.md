# Berkut Praha

Website for Berkut Praha hockey club.

## Live website

https://berkut-praha.jevg-pika.workers.dev/

## Features

- Upcoming games and countdown
- Match results and league standings
- Player statistics and profiles
- Club history and photo gallery
- Sponsors page
- Responsive layout for desktop and mobile

## Technologies

- HTML
- CSS
- JavaScript
- Cloudflare Workers
- PHM API integration

## My role

I manage the club and developed this website with AI assistance.
I defined the content, design direction and features, tested the
website and deployed it on Cloudflare.
